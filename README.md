# Samari Harper — персональное досье

Статический сайт-квента. GitHub Pages на текущем этапе не включён.

## Структура
- `index.html` — сайт
- `Images/` — изображения; портрет ожидается по пути `Images/samari-portrait.png`
- `music/` — аудиофайлы
- `font/` — шрифты; текущий CSS ожидает `font/your-font.woff2`

Названия каталогов чувствительны к регистру.

Закрытый раздел использует декоративную проверку пароля на стороне браузера. Пароль доступен в исходном JavaScript; не размещайте там конфиденциальные материалы.

GitHub Pages не настроен и не включён.
